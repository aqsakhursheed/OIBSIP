# Random Password Generator (Beginner)

## Project Description

This is a **Python-based Random Password Generator** developed as part of my **Python Programming internship at Oasis Infobyte**.

The program allows users to generate customized random passwords by specifying the desired password length and selecting the character types they want to include. It also includes input validation to ensure valid user input and provides an option to generate another password without restarting the program.

## Features

* **Custom Password Length** — Allows users to specify the desired password length, with a minimum requirement of 8 characters.
* **Character Type Selection** — Users can choose whether to include uppercase letters, lowercase letters, numbers, and symbols.
* **Minimum Character Type Requirement** — Requires users to select at least two character types before generating a password.
* **Random Password Generation** — Generates a random password based on the selected character types.
* **Input Validation** — Rejects invalid password lengths and invalid Yes/No responses.
* **Generate Again Option** — Allows users to generate another password without restarting the program.

## Technologies Used

* **Python 3**
* **random** — Used to randomly select characters from the selected character pool.
* **string** — Used to provide uppercase letters, lowercase letters, digits, and punctuation characters.

## How It Works

1. The user enters the desired password length.
2. The program checks that the password length is at least 8 characters.
3. The user is asked whether to include uppercase letters, lowercase letters, numbers, and symbols.
4. The program validates each Yes/No response.
5. The program checks that at least two character types have been selected.
6. A character pool is created according to the user's selections.
7. A random password is generated using the selected character pool.
8. The generated password is displayed to the user.
9. The user can choose to generate another password or exit the program.

## Project Purpose

The purpose of this project was to strengthen my understanding of **Python programming, loops, conditional statements, user input handling, input validation, string manipulation, and random character generation** by building a functional password generator.
